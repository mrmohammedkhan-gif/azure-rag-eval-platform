\# Enterprise RAG Evaluation \& Observability Platform



\## Overview

This project is an Azure-based Retrieval-Augmented Generation (RAG) application that answers questions from enterprise documents and evaluates answer quality.



\## Tech Stack

\- Azure OpenAI

\- Azure AI Search

\- Python

\- Streamlit

\- Phoenix Observability

\- Vector Embeddings



\## Features

\- Document ingestion

\- Text chunking

\- Embedding generation

\- Azure AI Search vector retrieval

\- Grounded answer generation

\- Retrieval quality evaluation

\- Grounding / hallucination evaluation

\- Token usage tracking

\- Latency tracking

\- Streamlit UI



\## Architecture

User question → Streamlit UI → Azure OpenAI embeddings → Azure AI Search → Retrieved documents → Azure OpenAI chat model → Evaluation layer → UI results



\## Example Questions

\- What does the company require for AI systems?

\- How should API keys be handled?

\- What are the compliance requirements for financial data?

\- What is the company vacation policy?



\## Business Value

This project demonstrates how enterprise AI teams can monitor, evaluate, and improve GenAI applications before production deployment.
